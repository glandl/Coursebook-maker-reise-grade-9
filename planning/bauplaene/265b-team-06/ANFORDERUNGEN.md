### US1 Licht sparen bei Tageslicht (Muss)
Als umweltbewusste Person möchte ich das sich meine Lampe automatisch abdreht, wenn draußen Tageslicht ist, damit ich während des Tages Strom sparen kann.
- [ ] Bei Tageslicht bleibt die Lampe durchgängig aus.

### US2 Ausschalten (Muss)
Als Privatperson möchte ich auch in der Lage sein die Lampe individuell einzuschalten, auch wenn draußen Tageslicht ist, damit ich trotzdem meine Lampe benützen kann wenn ich möchte.
- [ ] Bei individuellem Einschalten schaltet sich die Lampe ein.
- [ ] Bei nicht individuellem Einschalten soll die Lampe ausbleiben.

### US1 Ladegerät ausstecken (Muss)
Als umweltbewusste Person, möchte ich eine Erinnerung erhalten, mein Ladegerät nach dem Laden auszustecken, damit ich unnötigen Stromverbrauch.

-[ ] Benutzer soll eine Zeit festlegen können nach der er an das Ausstecken des Ladegeräts erinnert werden soll.
- [ ] Benutzer soll eine Erinnerung erhalten sobald die festgelegte Zeit abgelaufen ist.
- [ ] Benutzer kann Erinnerung mit Erledigt markieren.
- [ ] Die Erinnerung bleibt sichtbar, solange sie nicht als erledigt markiert ist.
- [ ] Benutzer kann die Zeit vor dem Start der Erinnerung festlegen.

**US1 Anzeichen für Temperatur Senkung (Muss)**

Als umweltbewusste Peron möchte ich dass, mir mithilfe eines Leuchten eines Lämpchens angezeigt wird wenn es im Zimmer zu heiß ist damit ich die Fenster öffnen oder die Klimaanlage aktivieren kann. Sobald ich meine gewünschte Temperatur erreicht habe geht dieses Lämpchen wieder aus und ich weiß das ich nicht mehr kühlen brauche.

- [ ] Das System misst laufend die Raumtemperatur.
- [ ] Wenn die Raumtemperatur höher als die gewünschte Temperatur ist, leuchtet ein Lämpchen.
- [ ] Wenn die gewünschte Temperatur erreicht oder unterschritten wird, schaltet sich das Lämpchen automatisch aus.
- [ ] Das Lämpchen muss gut sichtbar sein.
- [ ] Die Temperaturmessung muss zuverlässig funktionieren.
- [ ] Die gewünschte Temperatur muss vom Benutzer eingestellt werden können
