### US1 · Handy an bei drücken der Taste (Muss)

Ein Tastendruck schaltet das Handy EIN.

Ein weiterer Tastendruck schaltet das Handy AUS.


### US2 · Ausschalten (Muss)
Im ausgeschalteten Zustand bleibt das Display dunkel.

Der Zustand ändert sich bei jedem Tastendruck zwischen EIN und AUS.

The user stories are slightly confusing. Let us simplify them: There is a button that turns the device on and off. When the device is off, the display is dark. Each press of the button toggles the state between on and off. Let a LED represent the state of the device: when the device is on, the LED is lit; when the device is off, the LED is dark.
