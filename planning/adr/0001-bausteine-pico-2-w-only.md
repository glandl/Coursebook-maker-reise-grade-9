# Bausteine cover only the Raspberry Pi Pico 2 W

PLAN.md treats micro:bit, Pico, ESP32 and Arduino as equal, with per-board tabs. The Bausteine (Werkzeuge → Bausteine) deliberately break that rule: they show one wiring and one code block for the **Raspberry Pi Pico 2 W** only, without board tabs. Every team in both classes uses this board (decided 2026-11-09), the Bausteine had to be ready during P1 week 5, and one version halves the writing and verification effort and is easier for weaker students to follow. The P1 week pages keep their board tabs.

## Consequences

- Bausteine follow the Kurs-Verkabelung on Pico pins; they never introduce pins for other boards.
- If a later class uses other boards, tabs are added to each Baustein then. Pages are kept small so that retrofit stays cheap.
- Pico 2 W has WLAN, so the same Bausteine carry over to P2.
