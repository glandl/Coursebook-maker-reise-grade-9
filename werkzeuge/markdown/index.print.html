Markdown-Spickzettel

Markdown ist Text mit ein paar Sonderzeichen für die Formatierung. Dein Lernjournal ist in Markdown geschrieben, dieses Buch auch, README-Dateien auf GitHub sowieso. Du brauchst nur diese Handvoll Regeln.

Code-Blöcke

Mehrzeiliger Code kommt zwischen drei Backticks, dahinter die Sprache für die Farben:

```python
zustand = "AUS"
print(zustand)
```

wird zu

zustand = "AUS"
print(zustand)
